# MedCart – Order Details UI

This project is a pixel-perfect implementation of the MedCart "Order Placed" screen based on the provided Figma design for the LocalWell Frontend assignment.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Next.js Font Optimization (Poppins)

## Features
- Component-driven architecture
- Responsive layout (mobile + desktop)
- Fixed success panel with scrollable order summary
- Sticky action buttons
- Pixel-accurate Figma UI

## Live Demo
https://localwell-order-ui.vercel.app/

## Run Locally
npm install  
npm run dev
